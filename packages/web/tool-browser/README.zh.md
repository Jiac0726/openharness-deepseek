# @deepseek-ai/dsh-tool-browser

[English](README.md) | 中文

这是交互式浏览器自动化的模型侧消费者。它注册一个 `browser` 工具，使用带判别字段的操作完成标签页创建、导航、有界 DOM 快照、交互、滚动、键盘输入、列表查询和清理。

执行基于节点的操作前应调用 `snapshot`。快照节点 ID 是提供方拥有的临时句柄，页面变化后不得继续使用。

## 模型体验

### 浏览器工具结构与结果

#### 模型看到的内容

模型看到 [`browser`](../../../docs/tool-catalog.md#deepseek-aidsh-tool-browser) 工具结构，以及有界的页面可见文本、交互节点 ID、标签页元数据和操作失败信息。

#### Token 影响

挂载工具时，工具结构固定加入请求前缀。快照结果最多添加提供方配置的 `maxSnapshotChars` 个字符；其他结果只包含有界的标签页元数据。

#### KV 缓存影响

挂载、移除或修改工具定义会改变请求前缀。单次结果追加到会话日志，不会改变此前已经可复用的前缀。

## 已知限制与延期工作

- **仅有通用 UI 卡片**——浏览器专用的调用和结果卡片留待后续实现。
- **没有截图操作**——图片附件持久化和可重放呈现留待后续能力版本实现。
